# IPSwitcher

一个轻量级的 Windows IP 快速切换工具。专为需要频繁切换网络环境的用户设计，提供极致便捷的交互体验。

## ✨ 特色功能

- **暗色半透明悬浮窗**：现代化 UI 设计，支持拖动，视觉体验极佳。
- **一键切换 IP 方案**：支持双击快速切换预设的静态 IP 或 DHCP（自动获取）。
- **自动贴边隐藏**：点击“自动贴边”按钮，窗口将自动吸附至屏幕边缘并隐藏任务栏图标。
- **系统托盘支持**：后台静默运行，可通过托盘图标随时唤出。
- **全局快捷键**：支持自定义全局快捷键（如 `Ctrl+Alt+K`），一键显示/隐藏主界面。
- **配置自动保存**：你的所有 IP 预设方案及偏好设置均会自动保存。
- **极致小巧**：可选 UPX 压缩优化，提供轻量级的独立可执行文件。

## 🚀 快速使用

1. 在 [Releases](../../releases) 页面下载最新版的 `IPSwitcher.exe`。
2. 双击运行（程序需要管理员权限以修改网络配置，请在弹窗中允许）。
3. 界面操作说明：
   - 拖动顶部细条可移动窗口。
   - 右上角依次为：快捷键设置、自动贴边、最小化至托盘、关闭。
   - 在列表中**双击**对应的方案即可应用 IP 设置。
   - 点击 **+** 可添加新的 IP 方案，点击 **改** / **删** 进行管理。

> **⚠️ 注意**：如果安全软件/杀毒软件提示风险，这是由于打包工具（PyInstaller）及程序具有修改网络配置的系统权限导致的误报。你可以将其添加至白名单，或自行通过源码运行。

## 🛠️ 本地运行与开发

本工具基于 Python 构建，界面使用 `customtkinter` 编写。

### 环境依赖

```bash
pip install customtkinter pystray Pillow
```

### 运行源码

由于涉及修改网络适配器配置，请**以管理员身份**运行该脚本：

```bash
python IPSwitcher.py
```

### 构建打包

如果你希望自己编译生成 `.exe`，请运行以下命令：

```bash
pip install pyinstaller
python -m PyInstaller --noconfirm --clean IPSwitcher_Tray.spec
```
